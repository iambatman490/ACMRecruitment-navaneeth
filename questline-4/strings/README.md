
1.Valid Palindrome (LeetCode 125)
Approach: Two-pointer approach moving from both ends inward, skipping non-alphanumeric characters and comparing remaining characters case-insensitively.
Time Complexity: O(N)
space Complexity: O(1)
2. Zigzag Conversion (LeetCode 6)
Approach: Simulate the zigzag pattern by maintaining an array of strings for each row and reversing the vertical direction when hitting the top or bottom row.
Time Complexity: O(N)
space Complexity: O(N)
